# Запуск

Распакуйте `GPN_DELIVERY_CODE_PATCH.zip` в `/Users/wysockii/Documents/gpn_slides`.
Должна появиться папка `gpn_delivery_patch`.

Отправьте Space Bunny / OpenCode:

> Прочитай `/Users/wysockii/Documents/gpn_slides/gpn_delivery_patch/LAUNCH_PROMPT.md` и выполни его полностью. Примени приложенный код с сохранением моих изменений и продолжай существующий batch по всем трём презентациям. `awaiting_harness` означает, что ты сам должен выполнить очередное модельное задание. Дополнительное разрешение на продолжение этой работы не требуется.

Вам не нужно вручную заполнять `model_responses` или разбираться в ID заданий.

Пакет содержит готовый Python/JavaScript код, установщик с проверкой совместимости,
исходные версии для безопасного сравнения, тесты и результаты проверки.
Это патч существующего проекта, а не отдельная установленная программа.

Установщик сначала проверяет все файлы. При конфликте он не меняет код проекта.
Изменённые локально участки автоматически объединяются только при единственном
точном совпадении контекста; остальные конфликты должен разрешить агент по diff.
Перед записью создаются резервные копии. Git reset, commit и push не выполняются.

Автор патча проверил код на предоставленных снимках. Полный Mac-репозиторий,
ваши реальные шрифты и три исходных PPTX в этой среде недоступны, поэтому
интеграция и реальная визуальная приёмка выполняются следующим запуском на Mac.
Наличие ZIP не означает, что три презентации уже конвертированы.

Для следующей проверки агент должен собрать
`runs/recovery-batch-20261016T173142Z/delivery_review.zip`.
Полный список необходимых файлов указан в конце `LAUNCH_PROMPT.md`.
